## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/MonishGowdaSR/cipherfox-technologies-website.git
```

Navigate into the project:

```bash
cd cipherfox-technologies-website
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
